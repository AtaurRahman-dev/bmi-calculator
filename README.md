# 🧮 BMI Calculator (Python Jupyter Notebook)

This is a simple **Body Mass Index (BMI) calculator** built using Python in a Jupyter Notebook.

## 📌 What It Does

- Takes user input for **name, weight (lbs), and height (inches)**
- Calculates the **BMI**
- Gives a health classification:
  - Underweight
  - Normal
  - Overweight
  - Obese
  - Severely Obese
  - Morbidly Obese

## 🔧 Technologies Used

- Python 3
- Jupyter Notebook
